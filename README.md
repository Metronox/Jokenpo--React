# Jokenpô--React
Projeto de Jokenpô feito em react

Projeto desenvolvido como desafio técnico. 
O usuário escolhe Pedra, Papel ou Tesoura e joga contra o computador de forma interativa.

### Tecnologias utilizadas
- React
- Vite
- JavaScript
- CSS puro

### Funcionalidades
- Escolha entre Pedra, Papel ou Tesoura
- CPU faz escolha aleatória
- Exibe resultado da rodada (Vitória, Derrota ou Empate)
- Placar com contagem de vitórias, empates e derrotas
- Botão para reiniciar o jogo
- Layout responsivo e tema visual estilo Pixel Art

### Como executar o projeto
```bash
npm install
npm run dev
